# Food Planner App

A modern Android application that allows users to discover meals, save favorites, plan weekly meals, and sync data with Firebase Cloud.

---

##  Features

-  Search meals by name
-  View meal details with ingredients and instructions
-  Add / Remove favorites
-  Plan meals for specific dates
-  Sync favorites and planned meals with Firebase Firestore
-  Login with Email/Password or Google
-  Guest mode support
-  Play YouTube cooking videos inside the app
-  Offline support using Room Database
-  Reactive programming with RxJava

---

##  Tech Stack

- Java
- Android SDK
- Room Database
- RxJava3
- Firebase Authentication
- Firebase Firestore
- Glide (Image Loading)
- Android YouTube Player
